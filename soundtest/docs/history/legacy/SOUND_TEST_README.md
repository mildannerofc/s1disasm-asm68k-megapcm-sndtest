# Sonic 1 Sound Test V14

V14 contains the requested live DAC sample monitor, correct FM6/DAC row clearing, fixed note separators, extension-oriented sound ID constants, and a dedicated Sonic 1 ROM-hacking guide.

Current music range: `$81-$93`.

Normal SFX documentation range: `$A0-$CF`.

DAC sample display:
`81 KICK`, `82 SNARE`, `83 TIMPANI`, `84 CLAP`, `85 CYMBAL`, `88 HI TIMPANI`, `89 MID TIMPANI`, `8A LOW TIMPANI`, `8B VERY LOW TIMPANI`, `8C SEGACHANT`.

Controls remain explicit: Left/Right/A/B only select; C plays the selected music; START exits.
