sound driver.

| $A4 | SKID |
| $A5 | SFX A5 |
| $A6 | HIT SPIKES |
| $A7 | PUSH BLOCK |
| $A8 | SS GOAL |
| $A9 | SS ITEM |
| $AA | SPLASH |
| $AB | SFX AB |
| $AC | HIT BOSS |
| $AD | BUBBLE |
| $AE | FIREBALL |
| $AF | SHIELD |
| $B0 | SAW |
| $B1 | ELECTRIC |

| $B3 | FLAMETHROWER |
| $B4 | BUMPER |
| $B5 | RING |
| $B6 | SPIKES MOVE |
| $B7 | RUMBLING |

| $B9 | COLLAPSE |
| $BA | SS GLASS |
| $BB | DOOR |
| $BC | TELEPORT |

| $BF | CONTINUE |

| $C6 | RING LOSS |

normal Sound Test SFX range.
